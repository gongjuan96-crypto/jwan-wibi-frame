# jwan-wibi-frame

Jwan photo-to-retro-comic framed diptych Skill.

## Features

- Preserve the supplied photo in the upper half of a vertical 9:16 image.
- Create a small centered retro-comic avatar of the same subject below.
- Keep identity, pose, clothing, and important background context connected to the source.

![Case 01](examples/case-01.png)

## Usage

Use `$jwan-wibi-frame` followed by one photo. Add optional color, caption, or signature requirements.
